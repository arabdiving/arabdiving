# نظام البريد الإلكتروني — ArabDiving

منصة إرسال إيميلات مدمجة داخل الـ backend الحالي (Express + MongoDB). تدعم:
نشرة جماعية · تسلسل ترحيب تلقائي · نموذج اشتراك بموافقة (Double Opt-in) · إيميلات مخصّصة — مع امتثال قانوني كامل (السعودية 🇸🇦 ومصر 🇪🇬).

---

## ما الذي أُضيف؟

**الموديلات**
- `models/Subscriber.js` — المشتركون (حالة، دور، وسوم، سجلّ موافقة، رموز تأكيد/إلغاء).
- `models/EmailCampaign.js` — الحملات (النشرات الجماعية) وإحصاءاتها.
- `models/EmailSequence.js` — خطوات تسلسل الترحيب.

**المنطق**
- `lib/mailer.js` — الإرسال عبر SMTP (nodemailer) مع وضع محاكاة تلقائي.
- `lib/emailTemplates.js` — دمج المتغيّرات `{{name}}` + غلاف RTL + تذييل الامتثال.
- `lib/emailAutomation.js` — محرّك يرسل خطوات الترحيب تلقائياً كل دقيقة.

**الكنترولرز والراوتس**
- عام: `POST /api/newsletter/subscribe` · `GET /api/newsletter/confirm` · `GET /api/newsletter/unsubscribe`
- مشرف (يتطلب توكن أدمن): `/api/email-admin/*` (إحصاءات، مشتركون، حملات، تسلسل، إيميل مخصّص).

**الواجهات الجاهزة**
- نموذج الاشتراك: `http://localhost:5000/email/subscribe.html`
- لوحة التحكم: `http://localhost:5000/email/admin.html`

## التشغيل (3 خطوات)

```bash
cd backend
cp .env.example .env        # ثم عدّل القيم (MONGO_URI على الأقل)
npm install
npm run seed-welcome        # يثبّت تسلسل ترحيب جاهز من 4 خطوات
npm run dev                 # يشغّل الخادم + محرّك الأتمتة
```

- **بدون بيانات SMTP** يعمل النظام في **وضع المحاكاة (DRY_RUN)**: كل شيء يشتغل لكن الرسائل تُسجَّل في الـ console بدل إرسالها — مثالي للتجربة.
- **للإرسال الفعلي:** أنشئ حساباً مجانياً على [Brevo](https://www.brevo.com) → `SMTP & API` → انسخ بيانات SMTP إلى `.env`.

## استخدام لوحة التحكم

1. سجّل دخول الأدمن عبر `POST /api/auth/login` واحصل على الـ JWT.
2. افتح `/email/admin.html`، ألصق التوكن في الأعلى واضغط **حفظ**.
3. تنقّل بين التبويبات:
   - **الإحصاءات:** أعداد المشتركين حسب الحالة والدور.
   - **المشتركون:** بحث وتصفية.
   - **نشرة جماعية:** اكتب واختر الجمهور وأرسل فوراً (للمؤكَّدين فقط).
   - **تسلسل الترحيب:** عدّل/أضف خطوات (العنوان، المحتوى، التأخير بالساعات، الدور).
   - **إيميل مخصّص:** رسالة فردية لمشترك.

## الامتثال القانوني (مبنيّ داخل النظام)

- ✅ **Double Opt-in:** لا يُرسل شيء قبل أن يؤكّد المشترك بنفسه عبر رابط البريد.
- ✅ **رابط إلغاء اشتراك** في تذييل كل رسالة (تلقائي).
- ✅ **هوية المرسِل وعنوانه** في كل رسالة.
- ✅ **سجلّ موافقة** (وقت + IP + نص الموافقة) محفوظ لكل مشترك — مطلوب قانونياً.
- ✅ الإرسال للحالة **confirmed فقط**؛ الملغَون مستبعَدون آلياً.

> تذكير: التسويق الإلكتروني في مصر قد يتطلب ترخيصاً منفصلاً من مركز حماية البيانات (PDPC). راجع مستشاراً قانونياً قبل التوسّع.

## ملاحظات

- محرّك الأتمتة يعمل عبر `setInterval` داخل نفس عملية الخادم (لا حاجة لـ cron خارجي).
- للإرسال الجماعي الكبير: يُنصح بتفعيل تسخين الدومين تدريجياً وتوثيق SPF/DKIM/DMARC.
- المهلة بين الرسائل مضبوطة (~120ms) لتفادي حظر مزوّد SMTP.
